ESP32 & Node-Architecture

Apa Itu Smart Garden?

Smart Garden adalah inovasi sistem manajemen perawatan vegetasi berbasis Internet of Things (IoT). Berbeda dengan penyiraman tradisional, sistem ini memanfaatkan jaringan sensor otomatis untuk memantau kondisi tanah secara objektif tanpa spekulasi manusia.

Dengan mengintegrasikan perangkat keras di lapangan dan aplikasi web dashboard, Anda memiliki kendali penuh untuk menjaga siklus hidrasi tanaman tetap prima kapan saja dan di mana saja.

Cara Kerja & Alur Data Sistem

Bagaimana data mengalir dari akar tanaman hingga tersaji menjadi visualisasi grafik di layar gawai Anda.

1. Data Hambatan Sensor

Sensor Soil Moisture mengukur resistansi elektrik tanah. Jika tanah kering, hambatan tinggi (nilai ADC naik). Jika basah, arus listrik lancar (nilai ADC turun). Data diubah menjadi persentase skala 0% - 100% melalui proses kalibrasi matematika.

2. Transmisi API RESTful

Mikrokontroler ESP32 memproses parameter analog sensor. Melalui modul Wi-Fi internal, ESP32 melempar payload data berformat JSON menggunakan metode `HTTP POST` langsung ke endpoint API backend server Laravel secara terus-menerus (pooling).

3. Eksekusi Mekanis Relay

Server memvalidasi aturan (rule): Jika kelembaban di bawah batas minimum (Mode Otomatis), atau jam NTP sesuai target (Mode Jadwal), perintah balik dikirim ke ESP32 untuk memutus/menyambung arus listrik Relay 5V, memicu pompa air menyala dengan aman.

Tips Agrikultur Cerdas

Bahaya Overwatering

Tanaman membutuhkan oksigen di dalam pori-pori tanah. Menyiram terlalu sering hingga air menggenang membuat akar membusuk akibat bakteri anaerob (root rot). Gunakan ambang batas kelembaban maksimal 70% - 80% di sistem Anda untuk menghentikan pompa.

Manfaat Analisis Grafis

Gunakan menu riwayat statistik grafik di dashboard untuk membaca tren penguapan air harian tanaman Anda. Anda dapat menentukan jenis tanah mana yang mengikat air lebih lama dan mengatur durasi pompa menjadi lebih efisien.
